🔑 Simulador de Força Bruta

Demonstração educativa de como combinações de caracteres podem ser testadas até encontrar uma senha curta. Para manter o exemplo rápido, o simulador aceita no máximo 3 caracteres.

Tentativa: -
Aguardando início...
💡 Como funciona?

O programa cria combinações de caracteres e verifica cada uma delas. Por exemplo, usando abc, algumas tentativas serão:

a → b → c → aa → ab → ac → ba...

Quando uma combinação é igual à senha definida para o exercício, o programa interrompe o teste e informa quantas tentativas foram realizadas.
